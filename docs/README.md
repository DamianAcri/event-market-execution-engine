# Documentation

Start with the [implementation plan](project/IMPLEMENTATION_PLAN.md) for current
status, priorities and acceptance criteria. It is the single execution plan;
research documents explain the evidence and alternatives behind its decisions.
Unless a guide says otherwise, run its commands from the repository root.

[Contributing](CONTRIBUTING.md) covers development conventions and validation.
Research [results](research/results/) keep each report together with its evidence
and provenance; [tools](research/tools/) contain the offline reproduction tools.
Benchmark programs and measurements remain in [benchmarks](../benchmarks/).

Historical evidence manifests preserve the paths and hashes recorded when the
analysis ran. Their former `research/` paths now live under `docs/research/`;
the archived measurements have not been regenerated by this reorganization.
Third-party notices remain beside their vendored code.
